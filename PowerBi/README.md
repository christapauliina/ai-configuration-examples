# Power BI Sample Data

This folder contains the sample Power BI semantic model (`penguins-demo.pbix`) 

## Data Source
- **Source:** [Seaborn sample datasets](https://github.com/mwaskom/seaborn-data/blob/master/penguins.csv) (originally published by Gorman, Williams & Fraser, 2014; CC0 / public domain)

## Setup
1. Open `penguins-demo.pbix` in Power BI Desktop before running the `05.PowerBiMcp` demo application.
